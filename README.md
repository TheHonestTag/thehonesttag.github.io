# Hangnote

Garment life-cycle estimates, cradle to grave.

**Live site:** https://hangnote.de/

Hangnote estimates the environmental impact of garments (T-shirts, jeans, hoodies and more) across their whole life cycle: carbon footprint, water footprint, microplastic shedding and pesticide use, from fibre production to end of life. Available in English, Italian, Spanish and German.

## Files

| File | What it is |
|---|---|
| `index.html` | Home page: follow a garment from field to bin, read your own label, and keep a wardrobe |
| `breakdown.html` | Full Breakdown: the garment as a screening life cycle estimate (goal and scope, inventory, impact assessment, interpretation) |
| `calculator.html` | Methodology (all data and assumptions) and the earlier stage-by-stage calculator |
| `learn.html` | Learn page: short, sourced facts about clothes and the environment |
| `about.html` | About page: what the project is, independence, and how to send a correction |
| `legal.html` | Legal notice (Impressum) and privacy statement |
| `cookie-policy.html` | Cookie policy |
| `app3.js` | The calculator's code and data |
| `ht-i18n.js` | Translations for the calculator (IT, ES, DE) |
| `fonts/` | Self-hosted fonts (Inter, JetBrains Mono) with their licences |
| `og.png` | Preview image shown when a link is shared |
| `README.md` | This file |

All files sit side by side in the root of this repository, with the `fonts` folder next to them.
